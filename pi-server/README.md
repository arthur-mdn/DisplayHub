```
sudo apt-get update
sudo apt-get install git
cd ~
git clone https://github.com/arthur-mdn/DisplayHub.git
cd DisplayHub/pi-server
sudo ./install.sh
```

Pour activer les mises à jour système depuis l'administration, suivre
[SYSTEM_UPDATES.md](SYSTEM_UPDATES.md). L'activation est optionnelle et nécessite
une installation initiale privilégiée de la clé publique et du service sur le Pi.
